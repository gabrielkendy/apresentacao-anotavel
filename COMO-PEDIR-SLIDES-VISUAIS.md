# Inteligência de Slides Visuais — como pedir pro robô

> O robô (IA) desenha SVGs, gera imagens e monta slides didáticos com metáforas visuais.
> Menos texto, mais figura. É só pedir.

## Como pedir (3 exemplos)

1. **"Monta a apresentação de X com metáforas visuais, menos texto"**
2. **"Cria um slide visual mostrando como funciona o funil de vendas"**
3. **"Gera uma figura pra campanha de renovação de academia"**

## O que o robô usa

| Recurso | O que é | Exemplo |
|---|---|---|
| **SVG desenhado** | Vetores feitos à mão no código | Funis coloridos, gráfico de barras, setas, fluxos |
| **Imagem gerada por IA** | `image_generate` (FAL/OpenAI) | Foto de academia, ilustração de metáfora, fundo |
| **Emojis didáticos** | Ícones universais grandes | 🆕 💬 ⏳ 🔁 🎂 📱 ✉️ 📲 |
| **Cards + ícones** | Estrutura de dashboard claro | badges circulares, números grandes, glass suave |

## Metáforas visuais que já estão no deck

- **Capa**: 3 badges circulares coloridos (5 azul, 3 verde, 3x laranja)
- **Fórmula**: 3 células + operadores × (clientes, ticket, frequência)
- **Funis 1-5**: SVG de funil com gradiente colorido por público
- **3 canais**: cards com ícones grandes + linha de impacto
- **Matemática**: gráfico de barras SVG (500 vs 1.500) + foguete 🚀
- **Zápia**: 5 cards com ícones do sistema

## Regras do visual (pra ficar premium)

1. Máximo 1 accent por slide (verde esmeralda padrão)
2. Fundo branco/off-white, cards com borda + sombra suave (nada de drop preto)
3. Tipografia display bold com tracking negativo
4. Ícones/figuras maiores que o texto (visual manda)
5. Zero em-dash, zero gradiente roxo genérico
6. Uma ideia por slide

## Fluxo de criação (o robô faz)

1. Você dá o tema + público + mensagem
2. Robô desenha a metáfora visual (SVG) ou gera imagem por IA
3. Monta o slide com figura + título + 1 frase
4. Testa no browser e ajusta
5. Entrega o deck anotável pronto pra gravar
